# UnityLangPX 术语库功能指南

## 概述

UnityLangPX 术语库功能提供了专业术语的管理和应用能力，确保翻译过程中术语的一致性和准确性。该功能采用混合方案，结合传统术语库和RAG技术，既保证了精确匹配，又提供了智能推荐能力。

## 功能特性

### 传统术语库功能
- **精确匹配**：基于字符串的精确术语匹配
- **多语言支持**：支持多种语言对的术语管理
- **领域分类**：支持按领域组织术语
- **使用统计**：记录术语使用频率和时间
- **导入导出**：支持JSON、CSV、TXT格式的术语库导入导出

### RAG智能推荐（计划中）
- **向量检索**：基于SQLite-VSS的向量相似度搜索
- **上下文感知**：根据上下文选择最佳术语翻译
- **智能建议**：为未知术语提供翻译建议
- **自动学习**：从翻译结果中自动提取新术语

## 使用指南

### 桌面应用中的术语管理

#### 1. 打开术语库管理界面
- 在桌面应用主界面点击"工具"菜单
- 选择"术语库管理"
- 或使用快捷键 `Ctrl+T`

#### 2. 添加术语
1. 点击"添加术语"按钮
2. 填写术语信息：
   - 源术语：原文中的术语
   - 目标术语：目标语言的翻译
   - 源语言：术语的源语言
   - 目标语言：术语的目标语言
   - 领域：术语所属领域（如：技术、医学、法律等）
   - 上下文：术语的使用上下文（可选）
   - 置信度：术语翻译的可信程度（0-1）
3. 点击"保存"按钮

#### 3. 编辑术语
1. 在术语列表中选择要编辑的术语
2. 点击"编辑术语"按钮
3. 修改术语信息
4. 点击"保存"按钮

#### 4. 删除术语
1. 在术语列表中选择要删除的术语
2. 点击"删除术语"按钮
3. 确认删除操作

#### 5. 搜索和过滤
- **搜索**：在搜索框中输入关键词，支持源术语、目标术语和领域的搜索
- **语言对过滤**：选择特定的语言对进行过滤
- **领域过滤**：选择特定领域进行过滤
- **清空过滤**：点击"清空"按钮重置所有过滤条件

#### 6. 导入导出术语库
1. 点击"导入/导出"按钮
2. **导入**：
   - 选择文件格式（JSON、CSV、TXT）
   - 选择要导入的文件
   - 点击"导入"按钮
3. **导出**：
   - 选择文件格式（JSON、CSV、TXT）
   - 可选择按语言对和领域过滤
   - 选择保存位置
   - 点击"导出"按钮

### 翻译过程中的术语应用

术语库功能会自动集成到翻译过程中：

1. **自动匹配**：翻译时自动查找并应用匹配的术语
2. **使用统计**：每次使用术语时自动更新使用统计
3. **优先级匹配**：长词优先，确保术语的完整性
4. **边界检查**：确保只匹配完整的词汇边界

### 术语库文件格式

#### JSON格式
```json
{
  "terminology": [
    {
      "id": "unique-id",
      "source_term": "API",
      "target_term": "应用程序接口",
      "source_lang": "en",
      "target_lang": "zh",
      "domain": "技术",
      "context": "编程接口",
      "confidence": 1.0,
      "usage_count": 0,
      "user_preference_score": 0.5,
      "created_at": "2025-10-14 23:00:00",
      "updated_at": "2025-10-14 23:00:00"
    }
  ],
  "metadata": {
    "total_count": 1,
    "language_pairs": ["en-zh"],
    "domains": ["技术"],
    "last_updated": "2025-10-14 23:00:00"
  }
}
```

#### CSV格式
```csv
源术语,目标术语,源语言,目标语言,领域,上下文,置信度
API,应用程序接口,en,zh,技术,编程接口,1.0
GUI,图形用户界面,en,zh,技术,用户界面,1.0
```

#### TXT格式
```txt
# UnityLangPX 术语库导出
# 导出时间: 2025-10-14 23:00:00
# 格式: 源术语	目标术语	源语言	目标语言	领域

API	应用程序接口	en	zh	技术
GUI	图形用户界面	en	zh	技术
```

## 配置选项

### 术语库配置
在 `config/desktop_config.json` 中可以配置术语库选项：

```json
{
  "terminology": {
    "enable_traditional": true,
    "enable_rag": false,
    "enable_learning": false,
    "embedding_model": "bge-m3:latest",
    "vector_db_type": "sqlite-vss",
    "vector_db_path": "data/terminology_vectors.db",
    "auto_extract_threshold": 0.7,
    "max_suggestions": 5,
    "cache_size": 100,
    "confidence_threshold": 0.8,
    "auto_save": true,
    "backup_enabled": true
  }
}
```

### 配置说明
- `enable_traditional`：是否启用传统术语库功能
- `enable_rag`：是否启用RAG智能推荐功能
- `enable_learning`：是否启用自动学习功能
- `embedding_model`：嵌入模型名称
- `vector_db_type`：向量数据库类型
- `vector_db_path`：向量数据库存储路径
- `auto_extract_threshold`：自动提取术语的置信度阈值
- `max_suggestions`：最大建议数量
- `cache_size`：缓存大小
- `confidence_threshold`：术语匹配的置信度阈值
- `auto_save`：是否自动保存术语库
- `backup_enabled`：是否启用备份功能

## 最佳实践

### 术语管理建议

1. **术语标准化**
   - 使用标准化的术语翻译
   - 避免一词多译，保持一致性
   - 参考行业标准和权威资料

2. **领域分类**
   - 合理划分术语领域
   - 便于不同场景下的术语管理
   - 支持按领域过滤和导出

3. **上下文信息**
   - 提供详细的上下文描述
   - 帮助选择最合适的翻译
   - 提高翻译质量

4. **定期维护**
   - 定期清理不常用的术语
   - 更新过时的术语翻译
   - 备份重要的术语库

### 翻译流程建议

1. **翻译前准备**
   - 导入相关领域的术语库
   - 检查术语覆盖情况
   - 调整术语优先级

2. **翻译过程**
   - 启用术语自动匹配
   - 关注术语应用情况
   - 记录发现的新术语

3. **翻译后处理**
   - 检查术语一致性
   - 补充遗漏的术语
   - 更新术语使用统计

## 故障排除

### 常见问题

1. **术语不生效**
   - 检查术语库是否已启用
   - 确认语言对设置正确
   - 验证术语拼写是否准确

2. **导入失败**
   - 检查文件格式是否正确
   - 确认文件编码为UTF-8
   - 验证数据格式是否符合要求

3. **匹配不准确**
   - 调整词汇边界设置
   - 检查术语是否包含特殊字符
   - 考虑使用更精确的术语

4. **性能问题**
   - 减少术语库大小
   - 调整缓存设置
   - 考虑分领域管理术语

### 日志查看

术语库相关的日志会记录在应用日志中，可以通过以下方式查看：

1. 打开日志文件：`logs/unitylangpx.log`
2. 搜索关键词：`terminology`、`术语`
3. 查看错误和警告信息

## 扩展开发

### 添加新的嵌入模型

1. 在 `src/core/embedding_client.py` 中创建新的客户端类
2. 继承 `EmbeddingClient` 基类
3. 实现必要的方法：
   - `encode()`: 编码文本为向量
   - `get_dimension()`: 获取向量维度
   - `is_available()`: 检查模型可用性
4. 在 `EmbeddingClientFactory` 中注册新客户端

### 添加新的向量数据库

1. 在 `src/core/vector_store.py` 中创建新的存储类
2. 实现向量存储和检索功能
3. 在术语管理器中集成新的存储后端

### 自定义术语匹配算法

1. 扩展 `TerminologyMatcher` 类
2. 实现自定义的匹配逻辑
3. 重写相关方法：
   - `extract_potential_terms()`: 提取潜在术语
   - `find_exact_matches()`: 查找精确匹配
   - `_is_word_boundary()`: 检查词汇边界
