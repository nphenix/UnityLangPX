# UnityLangPX 自定义翻译模板功能指南

## 概述

UnityLangPX 桌面应用现在支持自定义翻译模板功能，允许用户创建、管理和应用自定义翻译模板，以提高翻译质量和一致性。本指南将详细介绍如何使用这一功能。

## 功能特性

### 核心功能
- **模板创建与编辑**：创建自定义翻译模板，设置前言提示和后处理提示
- **模板管理**：导入、导出、删除和搜索模板
- **模板应用**：在翻译过程中应用选定的模板
- **预设模板**：提供多种场景的预设模板，如技术文档、学术论文、小说等

### 高级功能
- **变量替换**：支持在模板中使用变量，如 `{text}`、`{source_lang}`、`{target_lang}` 等
- **模板预览**：在应用前预览模板效果
- **模板验证**：自动验证模板的完整性和有效性
- **模板持久化**：模板数据自动保存，重启应用后仍然可用

## 使用方法

### 1. 访问模板管理

1. 启动 UnityLangPX 桌面应用
2. 点击菜单栏中的"工具" → "模板管理"
3. 或点击工具栏中的"模板"按钮

### 2. 创建新模板

1. 在模板管理窗口中，点击"新建模板"按钮
2. 填写模板基本信息：
   - **模板名称**：给模板起一个描述性的名称
   - **模板描述**：简要说明模板的用途和适用场景
   - **源语言**：选择模板适用的源语言
   - **目标语言**：选择模板适用的目标语言
3. 设置提示内容：
   - **前言提示**：在翻译前发送给模型的指令，用于指导翻译风格和要求
   - **后处理提示**：在翻译后执行的检查和处理指令
4. 配置高级设置（可选）：
   - **变量设置**：添加自定义变量及其值
5. 点击"保存"按钮保存模板

### 3. 应用模板

1. 在主界面选择要翻译的文件
2. 配置翻译参数（源语言、目标语言、模型）
3. 从"翻译模板"下拉框中选择要应用的模板
4. 点击"开始翻译"按钮

### 4. 管理现有模板

#### 编辑模板
1. 在模板列表中选择要编辑的模板
2. 在右侧编辑器中修改模板内容
3. 点击"保存"按钮保存更改

#### 删除模板
1. 在模板列表中选择要删除的模板
2. 点击"删除"按钮
3. 确认删除操作

#### 导入/导出模板
1. 点击"导入"按钮选择模板文件进行导入
2. 点击"导出"按钮将选中的模板导出为文件

#### 搜索模板
1. 在搜索框中输入关键词
2. 系统会实时筛选匹配的模板

## 模板语法

### 基本变量

- `{text}`：将被翻译的原始文本替换
- `{source_lang}`：源语言名称
- `{target_lang}`：目标语言名称

### 示例模板

#### 技术文档翻译模板
```
请将以下英文技术文档翻译为中文，要求：
1. 保持专业术语一致性
2. 保留代码块和链接格式
3. 确保技术概念准确传达
4. 保持原文档结构和层次

原文档：
{text}
```

#### 学术论文翻译模板
```
请将以下英文学术论文翻译为中文，要求：
1. 保持学术严谨性和专业性
2. 专业术语使用标准译法
3. 保持原文的逻辑结构和论证流程
4. 确保学术概念准确传达

原文：
{text}
```

#### 小说翻译模板
```
请将以下英文小说片段翻译为中文，要求：
1. 保持文学性和语言美感
2. 保留人物性格和情感表达
3. 适应中文阅读习惯
4. 保持故事的连贯性和节奏感

原文：
{text}
```

2. **学术论文翻译**：适用于学术论文、研究报告和期刊文章

## 最佳实践

### 1. 模板设计原则

- **明确性**：指令应清晰明确，避免歧义
- **简洁性**：避免冗长的指令，突出关键要求
- **具体性**：提供具体的翻译标准和要求
- **一致性**：保持模板风格的一致性

### 2. 前言提示设计

- 说明文本类型和领域
- 明确翻译风格和语气要求
- 指定专业术语处理方式
- 说明格式保留要求

### 3. 后处理提示设计

- 检查术语一致性
- 验证格式保留情况
- 确认语言自然流畅
- 检查特殊元素处理

### 4. 变量使用

- 合理使用变量提高模板复用性
- 避免过度复杂的变量嵌套
- 确保变量名称清晰易懂

## 常见问题

### Q: 如何备份我的自定义模板？

A: 可以通过"导出"功能将模板导出为JSON文件，建议定期备份重要的自定义模板。

### Q: 模板不生效怎么办？

A: 检查以下几点：
1. 确认已选择正确的模板
2. 检查模板语法是否正确
3. 验证变量是否正确设置
4. 查看错误日志了解具体问题

### Q: 可以在不同语言对之间共享模板吗？

A: 每个模板都绑定特定的语言对，如果需要在其他语言对中使用，可以创建副本并修改语言设置。

### Q: 模板支持多少字符？

A: 前言提示建议控制在2000字符以内，后处理提示建议控制在1000字符以内，以确保最佳效果。

## 技术实现

### 数据结构

模板数据采用以下结构：
```json
{
  "id": "唯一标识符",
  "name": "模板名称",
  "description": "模板描述",
  "source_lang": "源语言",
  "target_lang": "目标语言",
  "pre_prompt": "前言提示",
  "post_prompt": "后处理提示",
  "variables": {
    "变量名": "变量值"
  },
  "created_at": "创建时间",
  "updated_at": "更新时间"
}
```

### 存储位置

模板数据存储在 `config/templates.json` 文件中，采用JSON格式，便于备份和迁移。

### 应用流程

1. 用户选择模板
2. 系统获取模板内容
3. 替换模板中的变量
4. 构建完整的翻译提示
5. 发送给翻译模型
6. 应用后处理逻辑（如果有）
